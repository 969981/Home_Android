# APK 文件结构与真实审计

## 入口
```bash
python tools/home.py audit --version 4.1.0
python tools/home.py extract --version 4.1.0
python tools/home.py scan --version 4.1.0
```

## 输出及其含义
- `reports/4.1.0/apk_entries.csv`：ZIP 内每个合法 Entry 原名、解压大小、压缩大小、CRC32、魔数及候选类型。
- `reports/4.1.0/summary.json`：APK SHA-256、ZIP 结构完整性、完整 CRC32 校验结果、总数及按类型分组。
- `reports/4.1.0/scan_summary.json`：解包后的实际 ELF、DEX、Unity 及资源候选。
- `reports/4.1.0/resource_candidates.csv`：对解包文件独立按文件头复检。
- `Unpack/4.1.0/apk/raw`：APK 不丢字节提取内容，不是反编译源代码。

## 分流
- Java/Kotlin DEX：JADX，区分 Java 层代码和原生库。
- `resources.arsc`、二进制 Manifest：Apktool / Android Build Tools，需单独保存可读 XML 与原始文件。
- ELF：记录架构、节区、BuildID；是否有 `libil2cpp.so` 不预先假定。
- `UnityFS`：UnityPy 或 AssetRipper；压缩包可能含外部 `.resS` 文件。
- 无格式或加密资源：保留原文件头和路径，另行研究，不能伪造成功。

## 安全验证
先检测 ZIP 路径穿越与 symlink，随后做所有 Entry CRC 校验；成功完成才解包。

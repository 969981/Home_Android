# 图片、Sprite 与多语言文本

## 图片
- `resources/4.1.0/images`：Texture2D PNG。
- `resources/4.1.0/sprites`：切出的 Sprite PNG，可与 Texture2D 区分。
- 图片名默认由源容器 SHA 摘要 + PathID + 安全化名称构成；防止重名覆盖。
- 验收必须能通过 Pillow 打开并校验；图集位置及原始来源关系需要进一步完善。

## 文本
- `resources/4.1.0/text`：TextAsset 保真导出。
- 中文、日文、英文、韩文等语言应根据真实 Locale ID / String ID 建对照，不要靠文件名猜测。
- 不同语言统一 `string_key` 外键，原始文本、语境与疑似角色 UI 名单列。
- 带二进制数据的 TextAsset 留存 .bin，不强制转换。

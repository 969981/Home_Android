## 之后真正应做的原生验证

前置条件：先解决实测的在线通信错误，使用自己的合法测试账号和 ARM64 **原生** Android 环境。Android x86_64+Native Bridge 能启动 ARM64 游戏不等于 Frida ARM64 RVA 在该环境能命中。

已知 4.1.0 静态观察点（来自既有 IL2CPP 研究，未在本轮动态验证）：

1. `ApiRequestAuthRegisterUser.CallAfterResponse` RVA `0x1D33294`，仅反映注册回调处理阶段；
2. `ResponseParamCommon.basic` 来源位置 `0x1D2BA60`，调用 `UDManager.SetBasic` RVA `0x1D763D0`；
3. `UD_Basic.utid` 为托管字符串引用偏移 `+0xF0`，不是裸 32 位整数；
4. `ID32 % 1000000` 仅是候选六位显示规则，仍需与官方 APP 的实际显示对账。

验证顺序：**正式授权的单个账号成功进入 HOME → ARM64 只读捕获 basic.utid → 与界面 ID 对账 → 去掉调试工具后退出重启仍保留同一 ID。** 未完成上述流程前，不应开展循环建号。

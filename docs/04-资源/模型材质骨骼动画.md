# 模型、材质、骨骼与动画

## 首轮执行的真实能力
UnityPy Mesh exporter 可以按原始顶点导出 OBJ；它不意味着已正确恢复材质贴图、骨骼、蒙皮或动作播放。

优先级：
1. Mesh -> OBJ 网格可读回且有顶点、面结构。
2. Material -> 着色器、纹理引用与参数索引。
3. SkinnedMeshRenderer -> bones、bindposes、权重、骨架空间变换。
4. AnimationClip -> 曲线、关键帧、目标路径，时间轴可回读。
5. GLB / glTF -> Blender 实际导入验证纹理、骨骼与动画。需要专门的 Blender/AssetRipper 适配器，不可假设首轮完成。

每项以游戏原生的 `容器+PathID` 为来源链；记录类型缺失、导出失败与纹理兼容性问题。对无法解码的压缩格式先统计，不得生成伪图片。
